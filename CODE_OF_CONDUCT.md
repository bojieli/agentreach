# Code of Conduct

## The short version

Be decent to people. Argue about code, not about each other.

## The longer version

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
version 2.1. In summary, participants can expect:

- **Technical disagreement is welcome and expected.** waldo depends on
  undocumented behaviour in closed binaries, so being shown you are wrong is
  routine and useful. Bring evidence; an experiment beats an opinion.
- **Harassment, personal attacks, and demeaning comments are not acceptable**,
  in issues, pull requests, commit messages, or anywhere else this project
  happens.
- **Assume good faith.** Contributors work with different harnesses, targets and
  userlands, and a report that sounds impossible is usually a machine you have
  not met yet.

## Reporting

Report unacceptable behaviour privately to the maintainer at the address on
their GitHub profile. Reports are handled confidentially. Maintainers who do not
follow this in good faith may face consequences decided by other maintainers.

For **security** problems, use GitHub Security Advisories instead — see
[SECURITY.md](SECURITY.md).
